# 🛒 Ecommerce Sales Dashboard

An interactive Power BI dashboard designed to analyze and visualize e-commerce sales performance, customer trends, profitability, and payment preferences across various states in India.

---

## 📊 Project Overview

This dashboard provides a comprehensive view of e-commerce metrics to help stakeholders track total revenue, overall sales volume, profitability, and average order value (AOV). It offers breakdown insights across regions, product categories, customer segments, and payment methods.

---

## Key Metrics (KPIs)

* **Total Sales Amount:** ₹438K
* **Total Quantity Sold:** 6K units
* **Total Profit:** ₹37K
* **Average Order Value (AOV):** ₹121.014K

---

## 🔍 Key Insights & Visualizations

1. **Profitability Trends (`Profit by Month`)**
* Tracks monthly profit variations throughout the year.
* Identifies high-performing months (e.g., January, December) versus months with negative profit margins (e.g., May, July).


2. **Regional Performance (`Sum of Amount by State`)**
* Displays sales performance across top states, led by **Maharashtra**, followed by **Madhya Pradesh**, **Uttar Pradesh**, and **Delhi**.


3. **Product Breakdown (`Sum of Quantity by Category` & `Profit by Sub-Category`)**
* **Categories:** Clothing leads volume at **63%**, followed by Electronics (**21%**) and Furniture (**17%**).
* **Sub-Categories:** **Printers** and **Bookcases** yield the highest profit margins, while items like **Tables** generate lower or negative returns.


4. **Customer Insights (`Sum of Amount by CustomerName`)**
* Ranks top individual customers by revenue (e.g., Harivansh, Madhav, Madan Mohan, Shiva).


5. **Payment Method Analysis (`Sum of Quantity by PaymentMode`)**
* **Cash on Delivery (COD)** accounts for the largest share at **44%**, followed by **UPI (21%)**, **Debit Card (13%)**, **Credit Card (12%)**, and **EMI (10%)**.

## 🚀 How to Use / View

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/ecommerce-sales-dashboard.git

```


2. **Open the Dashboard:**
* Download and install [Power BI Desktop](https://powerbi.microsoft.com/).
* Open the `.pbix` file included in the repository.


3. **Interact:**
* Use the **Quarter Slicers** (`Qtr 1`, `Qtr 2`, `Qtr 3`, `Qtr 4`) at the top right to filter data dynamically by time frame.
